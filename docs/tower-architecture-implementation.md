# 도전의 탑 2.5D 건축 맵 + 공 충돌 탄성 구현 기록

2026-10-31 · `oibung_six_tower_2_5d_map_spec.md` 기반

## 적용 완료

- 6개 탑별 독립 폴리곤 건축 구성: 시간(톱니 고리/중앙 시계/계단), 우주(4개 부유 섬/에너지 브리지), 화염(현무암 절벽/분화구/건넘돌/성채), 폭풍(절벽/성루/협곡 통로), 빙결(호수/다층 빙판/측면 계단), 숲(거목/석조 터/뿌리 다리).
- 각 표면은 동일한 `vertices`, `z`, `kind` 데이터를 사용하여 월드 높이(`heightAt`), 실제 보행 가능 영역, 경계 충돌, 다각형 윗면/측면을 계산한다.
- 탑 화면의 공통 정사각 바닥판을 그리지 않으며, 탑별 허공/심연 색상을 그린다. 지형 밖에서는 마지막 안전 위치 또는 가장 가까운 유효 표면으로 밀어 복귀한다.
- 낮은 곳에서 높은 곳으로 단번에 걸어오르는 움직임을 제한하고, 계단·경사로를 통한 접근과 타워 AI 중간 경로점을 추가한다.
- 높은 탑 구조물은 실제 충돌체이고, 탑을 떠나면 타워 전용 상태를 정리한다. PvP에 탑 지형이 섞이지 않는다.
- 실제 접촉 또는 벽 반사 방향으로 공의 외형만 압축 → 반대 방향으로 미세 신장 → 복원하는 효과 `ArenaBallSquash` 구현. 캐릭터 반경, 속도, HP, 스킬 피해량을 건드리지 않음.
- 커스텀 직사탄은 점프 중인 타깃의 고도를 비행 중 제한된 각속도로 따라가고, 곡사/포탑 발사체의 도착 고도도 보정한다. 기존 지형 차폐 판정은 유지한다.
- 고지 위 패턴의 수직 연출은 현재 고도에 맞춘다.
- 지형 및 탄성 회귀 테스트를 추가했다.

## 여전히 추가 검증이 필요한 항목

- 사격·빔·근접·환경 장판을 완전하게 통일한 **3D 캡슐/체적 충돌체**는 다음 단계로 남아 있다.
- 연결 경로 AI는 다리/계단의 간단한 그래프를 사용한다. 좁은 길에서 다수 소환수가 엉키는 경우와 고급 경로 탐색은 실전 검증이 필요하다.
- 짧은 프레임 간 낙하와 수직 벽 이탈 등 고난도 물리 현상은 현재 안정적인 복귀/경계 반사를 우선한다.
- 모바일/PC 실제 장면과 프레임률은 브라우저 실측이 필요하다. 자동 테스트만으로 렌더링 품질은 보장하지 못한다.

## 파일

- `js/features/tower-map-architecture.js`: 6개 탑 독립 지형, 고도, 충돌, 렌더, 간단 경로점
- `js/features/tower-terrain-25d.js`: 이전 타워 API와 신규 아키텍처 연결, 기믹 유지
- `js/features/ball-impact-squash.js`: 접촉 탄성 시각 애니메이션
- `js/core/engine.js`, `js/core/render.js`: 충돌 이벤트와 시각 변형 연결
- `js/features/advanced-combat.js`, `js/features/skill-forge.js`: 수직 목표 추적
- `js/features/arena-depth.js`, `js/features/tower-pattern-25d.js`: 타워 바닥·고도 표시

원본 명세서는 의도/목표의 기준이며 본 문서는 실제 구현 범위에 대한 검증 가능한 기록이다.
