# 오이붕 아레나 — 평평한 전장·해설자·결전 개선

- 여섯 탑의 이동 가능한 발판 높이는 전부 0. 건너는 다리·빈 공간·외벽 충돌·탑별 배경·위험 기믹은 유지.
- 점프와 비행은 별개 z/수직 속도와 중력으로 작동. 타격 시 튕김·찌그러짐은 계속 사용.
- 결전: 일반전투 300초 또는 150초 무진전, 탑 420초 또는 180초 무진전 후 개시. 개시 후 최대 300초 뒤 무승부 (실제 고배속은 프레임율에 좌우).
- 탑 난이도: 최종 층 HP 배율 +175%, 피해저항 최대 28% (기존 +325%, 53% 대비 완화).
- 이전 기록 기준 최고 클리어 층과 다음 해금 층으로 이동. 이미 클리어한 층 재도전 허용; 기록의 최고값 보존.
- 포인트·우승 예측·가챠·스킨 장착 UI 및 실제 사용 모듈 제거. 기존 브라우저 저장 데이터는 강제 삭제하지 않음. 이중에서 기존 구매 아이템의 전투상 효과가 남는지 별도 점검 가능.
- 해설자 참고 일러스트는 제공된 4개 포즈를 벡터 윤곽으로 변환, 상황별 네 표정 선택.
- 대형 스킬은 2.5D 이펙트 공통 레이어에 별도의 기둥·광륜·수직 낙뢰 추가, 추가 피해 없음.
