# 주기형 스킬의 연출·전투 효과 분리 (2026-10-31)

## 플레이어 체감

- `주기적으로` 설정과 블록 조합, 개별 스킬 쿨타임은 그대로 저장됩니다.
- 설정된 쿨타임이 0.6초 이하인 자동 스킬은 **0.1초(시뮬레이션 6프레임)** 간격으로 소형 마법진을 추가 재생합니다. 마법진은 시각 효과만 담당하며 피해, 힐, 제어, 생성체를 만들지 않습니다. 실제 공격과 이펙트는 기존 스킬을 그대로 재사용합니다.
- 게임 화면 효과 줄이기 설정을 적용하면 추가 마법진은 생략됩니다. 전투 멈춤 및 1~100배속은 모두 동일한 시뮬레이션 틱을 사용합니다.
- 실제 스킬 쿨타임 하한은 기존과 동일한 0.2초입니다. 시간 가속 상태에서 쿨타임 충전은 빨라질 수 있습니다.

## 밸런스 기준

- 화력·회복 예산의 쿨타임 하한을 실제 0.2초와 일치시켰습니다.
- 시간 가속의 예상 유지 비율을 화력·회복 예산 모두에 반영했습니다.
- 체력이 95% 이하일 때 발동하는 스킬은 거의 상시 발동에 가까우므로 낮은 체력 조건의 할인을 그대로 받지 않도록 조정했습니다.
- 내구도 목적의 벽은 실제 공격 피해가 아니므로 공격 예산에서 제외합니다.
- 빙결은 최대 84프레임, 기절은 72프레임, 속박은 105프레임, 침묵은 90프레임입니다. 강력한 군중 제어를 받은 대상은 해당 제어 시간과 추가 72프레임의 짧은 회복 시간을 공유합니다. 시각 효과는 계속 재생됩니다.
- 커스텀 보호막은 같은 캐릭터의 **보호 에너지**를 소비합니다. 초당 0.7초 분량이 회복되며, 장기 시전 스킬은 더 큰 초기 에너지 저장량을 가집니다. 탑 전용 적의 방어 패턴은 변경하지 않습니다.
- 커스텀 회복은 기존 방어 효율 보정 후 한 캐릭터의 **회복 에너지**를 사용합니다. 한 번의 일반적인 회복을 막지 않는 초기 저장량(최소 140 HP, 최대 체력 40%)과 지속 회복량(초당 최대 체력 24%)을 적용합니다. 생명의 꽃, 직접 회복, 흡혈, 회복형 시간 역행은 같은 에너지를 사용합니다. 탑 전용 적은 면제입니다.
- 지속 재생·출혈·감전은 상태 재적용 시 기존의 0.5초 피해/회복 카운터를 유지하고, 화상·중독도 0.5초 주기를 유지합니다. 빠른 갱신으로 발동이 사라지지 않습니다.
