# 오이붕 아레나 — 게임 개성 강화 제안

## 변하지 않을 핵심

**똑똑하게 부딪히는 공, 직접 조합한 황당한 기술, 전투를 과장되게 중계하는 아레나.** 전술 AI나 높은 탑 지형은 이 세 가지를 돕는 도구로 사용한다. 캐릭터를 사람형으로 바꾸거나 구슬의 반동을 제거하지 않는다.

## 우선순위 및 구현 위치

| 우선 | 사용자 경험 | 구체적인 개성 | 코드 연결 후보 |
|---|---|---|---|
| P0 | 충돌 순간 | 공끼리 들이받을 때 짧고 묵직한 충격음, 압축/복원, 벽 반사 순간 스파크; 충돌마다 발생하는 중복 데미지는 추가 금지 | `js/core/engine.js`, `js/features/impact-physics.js`, `js/features/vfx-audio.js` |
| P0 | 스킬 제작 | 블록 연결별 고유 문장과 기술 이름을 AI 해설자가 실제로 부르기; 자주 쓰는 스킬도 대사를 반복하지 않기 | `js/features/skill-forge.js`, `js/features/battle-director.js`, `js/features/block-forge.js` |
| P1 | 탑별 독립성 | 시간·우주·화염·폭풍·빙결·숲 각각 서로 다른 지형 실루엣·고도·물리 규칙; 참고 명세서의 3개 발판 골격을 건축물형으로 교체 | `js/features/tower-terrain-25d.js`, `js/features/tower-realms.js` |
| P1 | 캐릭터 개성 | 구슬 외형은 유지하고 질량감, 탄성, 충돌 잔향, 스킬의 소리·색·문양을 캐릭터별로 차별화. 숫자 유료 성장에 묶지 않기 | `js/features/character-remix.js`, `js/features/impact-physics.js` |
| P2 | 한 경기의 흐름 | 시작 충돌, 역전 직전, 콤보 적중, 결전 상태에 서로 다른 중계 톤과 연출. 결과는 실제 관측값으로만 보도 | `js/features/battle-director.js`, `js/features/arena-stalemate.js` |
| P2 | 게임 정체성 | 대기실에 구슬이 굴러가는 리듬감, 커스텀 캐릭터의 능력 시연, 탑 입장 때 탑별 효과 | `css/lobby-atmosphere.css`, `js/features/tower-ui-cinematics.js` |

## 피해야 할 방향

- 캐릭터 모두가 애니메이션만 화려하고 부딪히지 않는 전투
- 스킬마다 피해/피격 연출이 지나쳐 총알과 상태이상이 안 보이는 화면
- 탑마다 색만 다르고 높이·이동·보스 패턴은 동일한 구조
- 실제로 맞지 않았는데 "명중" 또는 "결정타"라고 중계하는 해설
- 전투를 알아서 진행하는 전략 AI라는 명목으로 구슬의 튕김 물리를 제거하는 수정

## 성능 원칙

투사체가 많아질수록 **그림자 → 잔상 → 장식 입자** 순으로만 연출 품질을 단계적으로 낮춘다. 실제 탄환의 이동·적중·상태이상·발사 수는 성능 보정으로 변경하지 않는다.
