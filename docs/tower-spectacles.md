# 속성 탑 대형 기믹

잡몹은 층별 2~3개 속성 스킬을 사용한다. 5층 보스는 속성별 대형 기믹 2개, 10층은 3개를 순환한다. 첫 대형 기믹은 전투 시뮬레이션 241틱에 시작하고, 이후 900틱 간격으로 발생한다. 대형 기믹 중에는 기존 보스 패턴의 신규 발동을 쉬며, 이미 예고한 공격은 유지한다.

| 속성 | 대형 기믹 및 대응 |
| --- | --- |
| 시간 | 실제 회전하는 바늘 회피, 양측 전투원/스킬/투사체의 과거 재생과 현재 복귀, 중앙 안전지대 밖 시간 정지 |
| 우주 | 중심으로 흡인하는 블랙홀, 순차적으로 퍼지는 빅뱅 고리, 무중력 관성 및 은하 절단선 |
| 화염 | 별도 HP를 가진 운석 직접 파괴, 연속 화산 분화, 궤도를 따라 이동하는 화염 토네이도 |
| 폭풍 | 중심이 안전한 허리케인, 순차 낙뢰, 공중 보스와 천둥 강하 지점 |
| 빙결 | 공격 가능한 거울상/골렘, 중앙 안전지대가 있는 절대영도, 누적 한기와 빙창 눈보라 |
| 숲 | 뿌리 속박 및 수호수, 빠른 곤충 소환군, 수호수 생존 시 보스가 회복하는 재생의 비 |

운석은 등장 1초 후 공격 대상이 되며 5층 HP 65, 10층 HP 100이다. 8초 안에 파괴하지 못하면 화면으로 퍼지는 폭발을 0.75초 보여준 후 최대 HP 4배의 원시 피해를 기존 피해 처리기로 전달한다. 기존 방어/무적/높이 판정을 우회하는 강제 사망은 아니다. 운석 파괴 후에는 보스를 다시 공격한다.

소환체는 플레이어 명단에 추가하지 않는다. 따라서 승리 조건, 대진, 저장 캐릭터 수에 영향을 주지 않는다. 원래 캐릭터의 접촉/범위 공격과 Forge/AdvancedCombat 공격 대상 목록에 연결한다. 소환체 처치는 해당 기믹을 약화시키며 별도의 저장 보상은 없다.

시간 역행은 최근 4초의 전투원 수치/상태/스킬 큐와 AdvancedCombat 객체를 제한된 80개 스냅샷으로 저장한다. 3초 동안 과거로 이동했다가 시작 당시의 현재로 돌아온다. 이 동안 일반 전투 갱신은 중단한다. 층 진행, 영구 저장, 보상과 UI 기록은 되감지 않는다. 기존 단발성 화면 파티클까지 정확하게 복원하는 영상 리플레이는 아니다.

외형은 속성별 절차적 Canvas 애니메이션이다. 일반 캐릭터 외형과 온라인 전투는 보존한다. 보스와 소환체에는 실제 판정과 분리된 장식이 있으므로 외곽 장식 전체가 피격 범위는 아니다.

페이지 연출은 클릭을 가로채지 않는 Canvas를 사용한다. 폭풍의 전투 패널 흔들림은 종료/이탈 시 원복한다. OS의 동작 줄이기와 게임의 화면 효과 줄이기 설정을 따르며, 전투 일시정지는 기믹의 시간도 멈춘다.

## 검증

- node --test tests/*.test.cjs: 555개 통과.
- node tests/browser-tower-spectacle.cjs: Microsoft Edge, 여섯 10층의 실제 엔진 실행, 운석 직접 피격/우선 대상, 시간 역행, 일시정지, 포기 후 페이지 효과 정리, 390px 렌더링.
- 브라우저 검증은 층 이동과 생존 HP를 제어한 QA 시나리오이다. 정상 HP로 60개 층을 모두 클리어한 장기 밸런스 테스트와 실제 휴대폰 성능 측정은 별도로 필요하다.
