# 오이붕 아레나: 모든 이펙트의 2.5D 전환 설계

## 원칙
- 정해진 월드 좌표 (x,y)와 지형 높이 terrainZ, 추가 체공 고도 z를 동일한 기준으로 사용한다.
- 모든 효과는 **지면 그림자/경고**, **중간 높이 몸체**, **공중 파편**의 3개 렌더 패스로 구성한다.
- 뷰 투영은 ArenaDepth.elevatedPoint와 같은 함수를 재사용하고, hitbox/시뮬레이션은 렌더링과 분리한다.
- 높이에 따른 페이드와 블러는 화면 기반 무차별 효과가 아닌 발사체별로 예산을 제한한다.

## 종류별 가이드
- 근접 공격: 타격자 높이에서 부채꼴이나 칼 궤적을 그리고 지면에는 충격 그림자를 따로 그린다.
- 직사·유도 투사체: 3차원 `worldZ` 위치를 interpolation해서 비행. 그림자는 `floorZ`에 그린다.
- 곡사·낙하: 3D 비행 곡선과 지면 타격 예고를 일치. 발사/명중 높이 판정은 원본을 유지한다.
- 충격파: 경고 지면 타원, 상승하는 입체 벽, 떠오르는 파편 세 요소를 순서대로 노출한다.
- 번개·폭풍: 상공 시작점과 지면 접점, 잔류 전기 아크를 분리한다.
- 화염·빙결·뿌리: 지면 텍스처 → 높이를 가진 기둥/결정/뿌리 → 파편/연기를 따로 렌더한다.
- 블랙홀·우주: 지면 중력 그림자, 공중 중심체, 궤도 조각을 서로 다른 투영 좌표로 처리한다.
- 방어막·회복·상태이상: 캐릭터 `z+groundZ`를 따라 움직이고 지면에 지문을 남기지 않는다.

## 성능·품질 검증
1. 2인전과 10인전, 1x~100x에서 같은 피해/명중/쿨타임을 유지한다.
2. 화면 밖 파편 컬링, 고밀도 이펙트 표현 간소화, reduce-motion 및 효과 줄이기를 지원한다.
3. 높은 발판 뒤 직사탄 차단, 곡사탄 통과, 공중 유도탄 적중 회귀 테스트를 추가한다.
4. 공통 fx 렌더 파이프라인부터 차례로 교체하며, 모든 개별 이펙트가 전환되기 전에는 완료로 표시하지 않는다.

## 2026-10-31 공유 파이프라인 적용
- `js/features/arena-fx-depth.js`: `ground`, `column`, `impact`, `billboard` 기반 지형 고도 / 오브젝트 높이 / 프레임별 밀집도 예산 통합.
- `SkillVisuals`의 모든 등록 스킬 타입은 공통 바닥/수직 임팩트 레이어를 상속하며, 웨이브는 바닥 타원으로 투영. 커스텀 블록의 `ForgeComboFX`는 다중 스텝 링과 충격에 수직 광선 추가.
- `ForgeExpansion` 운석/소환 영역/지뢰/블랙홀/생명의 꽃, `AdvancedCombat` 투사체·설치물·착탄, `ImpactPhysics` 충돌 순간, `ArenaCharge`, `ArenaTelegraph` 예고, 기본 챔피언 폭발, `StatusVFX`, 도전의 탑 환경/패턴/대형 보스 장판을 통합.
- 새로운 드로잉 도우미는 **시각 효과 전용**이며 피해 판정과 스킬 쿨타임을 소유하지 않음.
- `ArenaDepth`의 원근 투영은 그대로 사용하되, 지면 고도를 분리함. PvP/일반 경기에는 탑 발판 고도를 적용하지 않음.
- 기존 스킬별 손그림 모티프와 웹페이지 전체 화면 특수 연출은 유지됨. 각 스킬이 완전한 3D 메시/체적 광원을 갖는 것은 아님.
- 주의: 모바일의 실제 체감 프레임률은 실기기 검증이 필요.
