# 오이붕 아레나 UI 사용성 점검 · 2026-11-02

**범위:** HTML, CSS, 주요 UI 모듈, 기존 자동 테스트 및 전투 엔진 연결을 점검했습니다.
**한계:** 이 표는 코드로 확인 가능한 문제와 검증 필요 항목을 구분합니다. 모든 PC·모바일 실기기에서 시각/청각 검사를 수행한 완전한 UX 인증은 아닙니다.

## 보스 전투 테스트의 실제 결과와 한계

직접 제작한 프로필:

- **캐릭터:** 천공 반사 수호자. `signatureVersion=1`, `archetype=legacy`, HP 500, 이동 속도 4.6 (정규 `SkillForge.normalize` 유효 범위)
- **스킬:** 성운의 연속 파동 (고유 스킬 **1개**, 순서대로 방어막 1개 → 회복 2개(각 120) → 파동 공격 9개(각 120, 반경 300))
- **결과:** 40가지 빌드/초기 위치 중 13회 최종 보스 처치. 최선의 결과: HP 3000 → 0, 캐릭터 HP 약 420.264 / 500, 기세 고유 스킬 10회, 2426 프레임(60 FPS 환산 약 40.4초), 봉인 촉수 접촉 피해 21회.
- **검증 방식:** `tests/ancient-authored-boss-attempt.test.cjs`에서 실제 `SkillForge`, `BounceMomentum`, 물리 및 고대의 존재 패턴/여섯 봉인 모듈을 연동한 진짜 HP 기반 **헤드리스** 실험.
- **절대 뜻하지 않는 것:** 사용자 계정 기록에 6개 탑 60층이 추가되거나, 실제 배포 사이트의 브라우저에서 게임을 플레이해 60층을 완주했다는 의미가 아님. 브라우저 렌더/모든 AdvancedCombat 객체/입력/배속 조건/실기기 FPS를 통째로 재현한 시험도 아님.
