# 오이붕 맞짱뜨기 시뮬레이터 · 분해판 (기본틀)

## 7개 테마 확장 · 랜덤 캐릭터 · 제작 화면 정리

실제 전투 동작은 **35종**, 상태 효과는 **15종**입니다. 새 테마도 API 없이
한국어로 입력하거나 **랜덤 초안 만들기**에서 선택할 수 있습니다.

| 계열 | 새 동작 | 실제 효과 |
|---|---|---|
| 공중 | 공중 강하 | 최대 3초간 직접 공격을 회피한 뒤 주변에 착지 피해 |
| 지하 | 지하 습격 | 최대 3초간 회피한 뒤 적 위치에서 솟아올라 범위 공격 |
| 우주 | 블랙홀·우주 별비 | 중력장의 흡입·주기적 피해 / 여러 별의 시간차 낙하 |
| 똥 | 똥 폭탄 | 갈색 투사체 명중 시 중독과 둔화 |
| 생명 | 생명의 꽃 | 자신의 위치에 설치하고 범위 안에 머무를 때 회복 |
| 부활 | 부활 | 스킬에 포함하면 경기당 1회 사망 시 체력 35%로 자동 부활 |
| 시간 | 시간 정지·되감기·가속 | 적의 이동·행동 최대 2초 정지 / 자신의 체력·위치 최대 3초 복원 / 스킬 충전 2배 |

시간 정지는 지속 피해를 멈추지 않고, 되감기는 이미 죽은 캐릭터나 전장 전체를 복원하지
않습니다. 부활은 발동 조건이나 쿨타임과 관계없이 스킬에 포함된 순간 적용되는 1회 특성입니다.
기존 사망 판정보다 먼저 처리하며 다시 죽으면 탈락합니다. 공중·지하에서도 이미 걸린 지속 피해는 받습니다.

랜덤 생성은 전체 랜덤 또는 7개 테마를 선택하여 이름·색상·체력·이동 속도와 3~4개 스킬을
조합합니다. 공격 수단을 포함하도록 구성하며, 먼저 초안과 능력 미리보기를 보여줍니다.
**캐릭터 생성**을 눌러야 보관함에 저장되고 P1에 적용됩니다. 기존 최대 6명 제한은 유지합니다.

제작 화면은 이름 → 랜덤/문장 제작 → 미리보기·생성 순서로 정리했습니다.
외형·수치, 세부 스킬, 공격 도감, 저장 설정은 접을 수 있으며 검은 캐릭터 테두리와
흰 경기장용 진한 이펙트를 유지합니다.

## 휴대폰 기본 모드 — API 없이 문장으로 제작

게임 링크를 열고 **커스텀 캐릭터 → 문장 분석 · 자동 생성**을 누르세요.
기본값은 **휴대폰 기본 · API 없이 분석**입니다. 모델 다운로드나 API 키,
별도 서버 없이 기기 안의 규칙으로 처리합니다. 기존 AI 모드는 선택 사항입니다.

- 실제 동작 **25종**: 기존 11종에 유도탄·관통탄·부메랑·연쇄 번개·주변 폭발·운석·지뢰·흡혈·위치 교환·후퇴·정화·가속·지속 재생·피해 감소를 추가했습니다.
- 상태 효과 **15종**(없음 제외): 둔화·화상·중독·빙결·기절·속박·침묵·출혈·감전·취약·공격 약화·공포·매혹·실명·회복 저주.
- 해석하지 못한 문장이나 독립 분신 AI 같은 미지원 기믹은 **어떤 효과인가요?** 선택 화면에서 구현할 동작을 지정합니다. ‘이 표현은 구현하지 않음’도 선택할 수 있습니다.
- 생성 결과에 실제 동작·상태·쿨타임을 표시합니다. ‘지원 동작 / 상태 효과’ 안내에서 각 효과의 정확한 동작을 확인할 수 있습니다.
- 새 설정도 기존 로컬 저장·JSON 공유를 사용합니다. 새 동작을 읽으려면 받는 쪽도 최신 버전이어야 합니다.

예시: `3초마다 감전 유도 미사일 3발을 발사한다`, `4초마다 연쇄 번개 3줄기를 쓴다`,
`체력 30% 이하에서 흡혈한다`, `5초마다 위치 교환 후 독 장판을 만든다`.

위 25종은 이전 확장의 내역이며, 현재는 새 테마 10종을 더한 총 35종입니다.
명시적인 표현과 유의어를 인식하는 방식으로, 모든 비유의 의도를 이해하지는 않습니다.
한 동작에는 상태 효과 1종을 선택하며, 여러 상태를 주려면 동작을 연결하세요.
빙결과 기절은 현재 이동·행동 정지라는 같은 판정을 사용하고, 화상과 중독도
지속 피해 판정을 공유합니다. 이름 수가 모두 독립적인 전투 기능의 수를 뜻하지는 않습니다.
침묵은 현재 기본 캐릭터의 행동/접촉 공격까지 멈춥니다. 정화는 제작기에서 부여한
상태와 공통 둔화·DoT를 제거하며, 기본 캐릭터의 모든 고유 상태를 제거하지는 않습니다.
새 투사체·설치물은 캐릭터당 최대 48개로 제한하며, 기존 4스킬 × 3동작 제한을 유지합니다.

## 창작 AI로 캐릭터 만들기

커스텀 캐릭터의 **해석 방식 → 창작 AI**는 키워드가 없는 비유나 설정도
문장 전체를 모델에 전달해 실행 가능한 스킬 조합으로 설계합니다.
예: “슬픔을 작은 별로 접어 적에게 뿌린다. 상처받으면 별들이 나를 지킨다.”
생성 결과에는 실제 구현 설명과 원문에서 각색한 부분이 표시됩니다.
미리보기와 세부 설정을 확인한 뒤 **캐릭터 생성**을 누르면 전투에 적용됩니다.

### AI 서버 실행 (Node.js 22 이상)

서버 환경변수에 `OPENAI_API_KEY`를 설정하고 다음 명령을 실행하세요.
키는 브라우저 코드, Git 저장소, 공유 JSON에 넣지 마세요.

```sh
node server/start.cjs
```

`http://127.0.0.1:3000`을 열어 사용합니다. 추가 패키지는 필요하지 않습니다.
`OPENAI_MODEL`로 구조화 출력을 지원하는 모델을 지정할 수 있으며 기본값은
`gpt-4.1-mini`입니다. `PORT`로 포트를 변경할 수 있습니다.
창작 AI를 선택한 경우에만 입력한 이름과 설명이 서버를 통해 OpenAI API로
전송되며 API 사용료가 발생합니다. API 키는 서버에만 유지됩니다.

이 서버는 로컬/개인용으로 루프백 주소에서 실행됩니다. 공개 서비스로 운영하려면
인증, 사용자별 사용량 제한과 HTTPS를 제공하는 서버에 `/api/forge`를 연결해야 합니다.
GitHub Pages나 HTML 파일만 열었을 때는 AI 서버가 없으므로 **기본 분석**을 사용하세요.
창작 AI 실패를 기본 분석 성공으로 바꾸어 표시하지 않습니다.

지원 범위는 위의 전투 동작과 기존 공격 배치·대상 선택의 조합입니다.
완전히 새로운 엔진 코드를 자동 실행하는 기능은 아닙니다. 전장 전체 되감기나 독립 분신 AI 등은
가까운 동작으로 각색하고 차이를 표시합니다. 최대 4스킬 × 3동작이며
모델 응답의 동작 종류, 수치, 필드를 검증한 뒤 전투에 연결합니다.
아래의 기존 기본 분석 설명은 **기본 분석 모드**에 해당합니다.

단일 HTML(`1vs1-multi-item-shop.html`)을 기능별 파일로 나눈 개발용 기본틀입니다. 동작 코드는 원본을 그대로 옮겼고, **사진(base64 이미지)만 제거**했습니다. 사진이 없으면 캐릭터 색 원 + 이름 첫 글자로 표시됩니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 사진을 쓰고 싶으면 `assets/`에 이미지를 넣고 `js/photos.js`의 안내대로 `loadPhoto(...)`를 호출하세요. `assets/`는 `.gitignore`로 커밋에서 제외됩니다.

## 새 캐릭터 추가 방법

1. `js/characters/<id>.js`에서 `CHARACTER_DEFS.push({... createInstance ...})`로 정의를 등록합니다.
2. 같은 파일에서 `BEHAVIORS.<id> = { order, update(self, target), onContact(self, other), drawBack(p), ... }`를 작성합니다.
3. `index.html`에 스크립트 태그를 추가합니다.

## 전투 물리·배속 안정화

- 충돌한 캐릭터를 분리하고 반발 방향을 대칭으로 계산해 비정상적인 가속을 방지합니다.
- 같은 위치에서의 충돌도 안전하게 처리하며, 과도한 속도는 최대 12px/시뮬레이션 틱으로 제한합니다.
- 1배속은 기본 60Hz, 2배속은 두 배의 시뮬레이션 진행 속도를 사용하고 캔버스는 화면 프레임당 한 번만 그립니다.
- 파티클과 피해 숫자는 일시정지하면 정지하며, 캐릭터별 아이템 이동속도 증가가 지속됩니다.
- 모든 스크립트를 로드해야 합니다. 게임 루프는 마지막 파일인 `js/features/battle-effects.js`에서 한 번만 시작합니다.


## Skill Forge 2.0 (자유 제작)

**화면**: 대진 설정 → **커스텀 캐릭터** 메뉴를 펼치세요.

캐릭터 이름, 체력(140~500), 이동 속도(0.6~5), 대표 색상을 정하고
스킬 **최대 4개**, 스킬마다 동작 **최대 3개**를 순서대로 연결합니다.

- 발동 조건: 주기적으로 / 체력 일정 비율 이하 / 접촉 시 / 피격 시
- 스킬별 쿨타임 0.2~30초, 체력 임계값 설정
- 동작 11종: 충격파, 투사체, 레이저, 낙뢰, 돌진, 순간이동, 회복, 방어막, 흡입, 회전 소환체, 지속 장판
- 각 동작 위력, 범위, 개수, 속도, 지속 시간, 넉백, 지연, 속성(둔화·화상·중독) 설정
- **능력 미리보기** 후 **캐릭터 생성**: 새 캐릭터가 P1에 배치됩니다.
- 생성 캐릭터는 브라우저 \`localStorage\`에 저장됩니다. 사진은 세션에만 유지됩니다.
- **설정 JSON 가져오기 · 내보내기**: 구성 수치를 공유하고 다시 불러올 수 있습니다.

기존 한국어 키워드 인식기는 제거했습니다. **임의의 문장을 완전히 이해해 새로운
게임 코드를 생성하거나 실행하는 기능은 아닙니다.** 지원되는 동작의 조합으로
실제 전투에 사용할 능력을 만듭니다. 자유로운 스크립트 실행은 보안상 지원하지 않습니다.
과도한 투사체/장판이 게임을 멈추지 않도록 활성 개수를 제한합니다.

## 문장으로 능력 자동 만들기

**대진 설정 → 커스텀 캐릭터**에서 설명을 쓰고 **문장 분석 · 자동 생성**을 누르세요.
지원 범위에서 자동으로 발동 조건, 쿨타임, 피해량, 공격 범위, 동작 순서,
상태이상, 지속 시간 등을 추출합니다. 이후 바로 캐릭터를 생성하거나
**스킬 세부 설정 (선택)**을 열어 원하는 값을 수정할 수 있습니다.

예시: "체력 30% 이하에서 3초마다 번개 3줄기를 떨어뜨려 피해 45를 준다. 그 후 방어막을 2초 유지한다."

브라우저가 한국어 입력을 지원하는 **LanguageModel Prompt API**를 제공하고 모델이 이미
사용 가능한 경우에는 기기 내 AI로 JSON 제작을 시도합니다.
그 외에는 한국어 문장 규칙으로 분석합니다. API 지원 여부 및
언어 지원은 기기마다 다릅니다. 지원되지 않는 기믹이나 자유로운 자연어를
완전히 구현한다는 보장은 없습니다. **지원되지 않은 표현은 확인 요청**을 표시하며,
보안상 사용자가 입력한 JavaScript 코드는 실행하지 않습니다.

## 내 캐릭터 삭제 / 공개 공유 저장소

- 만든 캐릭터 목록의 **삭제** 버튼으로 내 캐릭터와 로컬 저장 데이터를 제거합니다.
- **공유 캐릭터 저장소** 메뉴를 열고 내가 만든 캐릭터를 선택해
  **GitHub에 공유하기**를 누르면 내용이 입력된 GitHub Issue 작성 화면이 열립니다.
- GitHub 로그인 후 **Submit new issue**를 눌러야 공개됩니다.
  (앱이 임의로 GitHub에 게시하거나 사용자 비밀번호/액세스 토큰을 요구하지 않습니다.)
- 게임 안 공유 목록의 **새로고침**을 누르면 공개 GitHub Issues에서
  규격에 맞는 캐릭터 설정을 조회하고 **내 게임에 추가**할 수 있습니다.
- 공개 게시물을 삭제하려면 GitHub에서 해당 Issue를 닫거나 삭제하세요.
  **내 캐릭터 삭제** 버튼은 로컬 보관만 삭제하며 공개 글에는 영향을 주지 않습니다.
- GitHub 비인증 API 속도 제한과 최근 100개 게시물 조회 제한이 있습니다.
  외부 서버/데이터베이스가 없으며, 사진 이미지는 공개 공유되지 않습니다.

GitHub Issues는 공개 데이터입니다. 개인 정보/허락받지 않은 사진은 게시하지 마세요.


## Ability Atlas — 210개 실제 공격 동작 조합

스킬 제작기에 **공격 동작 도감 210가지**가 추가되었습니다.

공격 5종(투사체·광선·낙뢰·충격파·장판) ×
공격 배치 7종(직선 집중·부채꼴·방사형·일렬·십자·나선·무작위 산개) ×
대상 선택 6종(근거리·원거리·저체력·고체력·무작위·밀집 대상)
= **210개 전투 판정 조합**입니다.

단순 이름 차이가 아니라 실제 목표 선택, 투사체 발사 방향,
낙뢰/장판 중심 좌표, 빔 방향, 충격파 중심점 등이 달라집니다.
상태이상, 지속 시간, 동작 순서, 피해량, 개수까지 조정 가능하므로
실제 조합 가능 수는 훨씬 더 많습니다.

**사용법:** 커스텀 캐릭터 → 문장 분석으로 자동 생성하거나,
접힌 **공격 동작 도감 · 210가지**에서 검색해 선택합니다.
세부 설정에서는 각 동작의 공격 배치/대상 우선순위를 수정할 수 있습니다.

자연어 예시:
- "3초마다 가장 멀리 있는 적에게 부채꼴 화염탄 5발을 발사한다."
- "체력 30% 이하일 때 뭉쳐 있는 적에게 십자 모양으로 낙뢰 4줄기를 떨어뜨린다."
- "2초마다 체력이 가장 낮은 적의 주변에 나선형 장판 6개를 만든다."

**계수 기준:** 도감에는 210개의 서로 다른 *조합 프리셋*이 있으며,
210개의 독립적으로 새로 작성한 물리 엔진이 있는 것은 아닙니다.
모든 공격 배치는 투사체/광선/낙뢰/충격파/장판의 공통
전투 엔진을 재사용합니다. 복잡한 분신 AI·전장 전체 시간 되감기 등은 아직
독립적인 전투 기능으로 지원하지 않습니다.


## 한국어 유의어 / 문맥 해석 개선

캐릭터 능력을 설명할 때 정확히 같은 스킬 단어를 입력할 필요는 없습니다.
한국어 유의어를 공통 의미로 변환한 다음, 발동 조건과 동작 순서를 분리하여 전투에 적용합니다.

- 이동 · 순간이동 · 텔레포트 · 텔포 · 점멸 · 워프 → 텔레포트
- 번개 · 벼락 · 낙뢰 · 천둥 · 전격 · 뇌격 → 낙뢰
- 독 · 독딜 · 도트데미지 · 도트딜 · DOT · 중독 · 지속 피해 → 독 지속 피해(DoT)
- "3초마다 이동 후 독딜" → 3초 주기의 텔레포트 후 독 장판
- "2초마다 낙뢰로 독딜 20" → 낙뢰에 독 상태이상 부여
- "이동 속도 3.2" → 이동 속도 설정. 스킬 텔레포트로 오인하지 않음
- "5초 동안 독딜" → 피해량 5가 아니라 지속 시간 5초로 해석

독 장판은 처음 생성될 때도 명중 판정을 수행하며, 독 피해의
지속시간/주기적 피해량은 전투 루프에 반영됩니다.

기본 해석은 명시적인 유의어·문맥 규칙으로 작동합니다. 지원되는 기기에서는
브라우저 내장 언어 모델을 추가로 시도합니다. 전혀 새로운 동작이나
해석되지 않은 문장을 완벽히 구현한다는 보장은 없습니다.
