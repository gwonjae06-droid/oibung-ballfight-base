# 오이붕 맞짱뜨기 시뮬레이터 · 분해판 (기본틀)

## 7개 테마 확장 · 랜덤 캐릭터 · 제작 화면 정리

실제 전투 동작은 **35종**, 상태 효과는 **15종**입니다. 새 테마도 API 없이
한국어로 입력하거나 **랜덤 초안 만들기**에서 선택할 수 있습니다.

| 계열 | 새 동작 | 실제 효과 |
|---|---|---|
| 공중 | 공중 강하 | 최대 3초간 직접 공격을 회피한 뒤 주변에 착지 피해 |
| 지하 | 지하 습격 | 최대 3초간 회피한 뒤 적 위치에서 솟아올라 범위 공격 |
| 우주 | 블랙홀·우주 별비 | 중력장의 흡입·주기적 피해 / 여러 별의 시간차 낙하 |
| 똥 | 똥 폭탄 | 갈색 투사체 명중 시 중독과 둔화 |
| 생명 | 생명의 꽃 | 자신의 위치에 설치하고 범위 안에 머무를 때 회복 |
| 부활 | 부활 | 스킬에 포함하면 경기당 1회 사망 시 체력 35%로 자동 부활 |
| 시간 | 시간 정지·되감기·가속 | 적의 이동·행동 최대 2초 정지 / 자신의 체력·위치 최대 3초 복원 / 스킬 충전 2배 |

시간 정지는 지속 피해를 멈추지 않고, 되감기는 이미 죽은 캐릭터나 전장 전체를 복원하지
않습니다. 부활은 발동 조건이나 쿨타임과 관계없이 스킬에 포함된 순간 적용되는 1회 특성입니다.
기존 사망 판정보다 먼저 처리하며 다시 죽으면 탈락합니다. 공중·지하에서도 이미 걸린 지속 피해는 받습니다.

랜덤 생성은 전체 랜덤 또는 7개 테마를 선택하여 이름·색상·체력·이동 속도와 3~4개 스킬을
조합합니다. 공격 수단을 포함하도록 구성하며, 먼저 초안과 능력 미리보기를 보여줍니다.
**캐릭터 생성**을 눌러야 보관함에 저장되고 P1에 적용됩니다. 기존 최대 6명 제한은 유지합니다.

제작 화면은 이름 → 랜덤/문장 제작 → 미리보기·생성 순서로 정리했습니다.
외형·수치, 세부 스킬, 공격 도감, 저장 설정은 접을 수 있으며 검은 캐릭터 테두리와
흰 경기장용 진한 이펙트를 유지합니다.

## 휴대폰 기본 모드 — API 없이 문장으로 제작

게임 링크를 열고 **커스텀 캐릭터 → 문장 분석 · 자동 생성**을 누르세요.
기본값은 **휴대폰 기본 · API 없이 분석**입니다. 모델 다운로드나 API 키,
별도 서버 없이 기기 안의 규칙으로 처리합니다. 기존 AI 모드는 선택 사항입니다.

- 실제 동작 **25종**: 기존 11종에 유도탄·관통탄·부메랑·연쇄 번개·주변 폭발·운석·지뢰·흡혈·위치 교환·후퇴·정화·가속·지속 재생·피해 감소를 추가했습니다.
- 상태 효과 **15종**(없음 제외): 둔화·화상·중독·빙결·기절·속박·침묵·출혈·감전·취약·공격 약화·공포·매혹·실명·회복 저주.
- 해석하지 못한 문장이나 독립 분신 AI 같은 미지원 기믹은 **어떤 효과인가요?** 선택 화면에서 구현할 동작을 지정합니다. ‘이 표현은 구현하지 않음’도 선택할 수 있습니다.
- 생성 결과에 실제 동작·상태·쿨타임을 표시합니다. ‘지원 동작 / 상태 효과’ 안내에서 각 효과의 정확한 동작을 확인할 수 있습니다.
- 새 설정도 기존 로컬 저장·JSON 공유를 사용합니다. 새 동작을 읽으려면 받는 쪽도 최신 버전이어야 합니다.

예시: `3초마다 감전 유도 미사일 3발을 발사한다`, `4초마다 연쇄 번개 3줄기를 쓴다`,
`체력 30% 이하에서 흡혈한다`, `5초마다 위치 교환 후 독 장판을 만든다`.

위 25종은 이전 확장의 내역이며, 현재는 새 테마 10종을 더한 총 35종입니다.
명시적인 표현과 유의어를 인식하는 방식으로, 모든 비유의 의도를 이해하지는 않습니다.
한 동작에는 상태 효과 1종을 선택하며, 여러 상태를 주려면 동작을 연결하세요.
빙결과 기절은 현재 이동·행동 정지라는 같은 판정을 사용하고, 화상과 중독도
지속 피해 판정을 공유합니다. 이름 수가 모두 독립적인 전투 기능의 수를 뜻하지는 않습니다.
침묵은 현재 기본 캐릭터의 행동/접촉 공격까지 멈춥니다. 정화는 제작기에서 부여한
상태와 공통 둔화·DoT를 제거하며, 기본 캐릭터의 모든 고유 상태를 제거하지는 않습니다.
새 투사체·설치물은 캐릭터당 최대 48개로 제한하며, 기존 4스킬 × 3동작 제한을 유지합니다.

## 창작 AI로 캐릭터 만들기

커스텀 캐릭터의 **해석 방식 → 창작 AI**는 키워드가 없는 비유나 설정도
문장 전체를 모델에 전달해 실행 가능한 스킬 조합으로 설계합니다.
예: “슬픔을 작은 별로 접어 적에게 뿌린다. 상처받으면 별들이 나를 지킨다.”
생성 결과에는 실제 구현 설명과 원문에서 각색한 부분이 표시됩니다.
미리보기와 세부 설정을 확인한 뒤 **캐릭터 생성**을 누르면 전투에 적용됩니다.

### AI 서버 실행 (Node.js 22 이상)

서버 환경변수에 `OPENAI_API_KEY`를 설정하고 다음 명령을 실행하세요.
키는 브라우저 코드, Git 저장소, 공유 JSON에 넣지 마세요.

```sh
node server/start.cjs
```

`http://127.0.0.1:3000`을 열어 사용합니다. 추가 패키지는 필요하지 않습니다.
`OPENAI_MODEL`로 구조화 출력을 지원하는 모델을 지정할 수 있으며 기본값은
`gpt-4.1-mini`입니다. `PORT`로 포트를 변경할 수 있습니다.
창작 AI를 선택한 경우에만 입력한 이름과 설명이 서버를 통해 OpenAI API로
전송되며 API 사용료가 발생합니다. API 키는 서버에만 유지됩니다.

이 서버는 로컬/개인용으로 루프백 주소에서 실행됩니다. 공개 서비스로 운영하려면
인증, 사용자별 사용량 제한과 HTTPS를 제공하는 서버에 `/api/forge`를 연결해야 합니다.
GitHub Pages나 HTML 파일만 열었을 때는 AI 서버가 없으므로 **기본 분석**을 사용하세요.
창작 AI 실패를 기본 분석 성공으로 바꾸어 표시하지 않습니다.

지원 범위는 위의 전투 동작과 기존 공격 배치·대상 선택의 조합입니다.
완전히 새로운 엔진 코드를 자동 실행하는 기능은 아닙니다. 전장 전체 되감기나 독립 분신 AI 등은
가까운 동작으로 각색하고 차이를 표시합니다. 최대 4스킬 × 3동작이며
모델 응답의 동작 종류, 수치, 필드를 검증한 뒤 전투에 연결합니다.
아래의 기존 기본 분석 설명은 **기본 분석 모드**에 해당합니다.

단일 HTML(`1vs1-multi-item-shop.html`)을 기능별 파일로 나눈 개발용 기본틀입니다. 동작 코드는 원본을 그대로 옮겼고, **사진(base64 이미지)만 제거**했습니다. 사진이 없으면 캐릭터 색 원 + 이름 첫 글자로 표시됩니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 사진을 쓰고 싶으면 `assets/`에 이미지를 넣고 `js/photos.js`의 안내대로 `loadPhoto(...)`를 호출하세요. `assets/`는 `.gitignore`로 커밋에서 제외됩니다.

## 새 캐릭터 추가 방법

1. `js/characters/<id>.js`에서 `CHARACTER_DEFS.push({... createInstance ...})`로 정의를 등록합니다.
2. 같은 파일에서 `BEHAVIORS.<id> = { order, update(self, target), onContact(self, other), drawBack(p), ... }`를 작성합니다.
3. `index.html`에 스크립트 태그를 추가합니다.

## 전투 물리·배속 안정화

- 충돌한 캐릭터를 분리하고 반발 방향을 대칭으로 계산해 비정상적인 가속을 방지합니다.
- 같은 위치에서의 충돌도 안전하게 처리하며, 과도한 속도는 최대 12px/시뮬레이션 틱으로 제한합니다.
- 1배속은 기본 60Hz, 2배속은 두 배의 시뮬레이션 진행 속도를 사용하고 캔버스는 화면 프레임당 한 번만 그립니다.
- 파티클과 피해 숫자는 일시정지하면 정지하며, 캐릭터별 아이템 이동속도 증가가 지속됩니다.
- 모든 스크립트를 로드해야 합니다. 게임 루프는 마지막 파일인 `js/features/battle-effects.js`에서 한 번만 시작합니다.


## Skill Forge 2.0 (자유 제작)

**화면**: 대진 설정 → **커스텀 캐릭터** 메뉴를 펼치세요.

캐릭터 이름, 체력(140~500), 이동 속도(0.6~5), 대표 색상을 정하고
스킬 **최대 4개**, 스킬마다 동작 **최대 3개**를 순서대로 연결합니다.

- 발동 조건: 주기적으로 / 체력 일정 비율 이하 / 접촉 시 / 피격 시
- 스킬별 쿨타임 0.2~30초, 체력 임계값 설정
- 동작 11종: 충격파, 투사체, 레이저, 낙뢰, 돌진, 순간이동, 회복, 방어막, 흡입, 회전 소환체, 지속 장판
- 각 동작 위력, 범위, 개수, 속도, 지속 시간, 넉백, 지연, 속성(둔화·화상·중독) 설정
- **능력 미리보기** 후 **캐릭터 생성**: 새 캐릭터가 P1에 배치됩니다.
- 생성 캐릭터는 브라우저 \`localStorage\`에 저장됩니다. 사진은 세션에만 유지됩니다.
- **설정 JSON 가져오기 · 내보내기**: 구성 수치를 공유하고 다시 불러올 수 있습니다.

기존 한국어 키워드 인식기는 제거했습니다. **임의의 문장을 완전히 이해해 새로운
게임 코드를 생성하거나 실행하는 기능은 아닙니다.** 지원되는 동작의 조합으로
실제 전투에 사용할 능력을 만듭니다. 자유로운 스크립트 실행은 보안상 지원하지 않습니다.
과도한 투사체/장판이 게임을 멈추지 않도록 활성 개수를 제한합니다.

## 문장으로 능력 자동 만들기

**대진 설정 → 커스텀 캐릭터**에서 설명을 쓰고 **문장 분석 · 자동 생성**을 누르세요.
지원 범위에서 자동으로 발동 조건, 쿨타임, 피해량, 공격 범위, 동작 순서,
상태이상, 지속 시간 등을 추출합니다. 이후 바로 캐릭터를 생성하거나
**스킬 세부 설정 (선택)**을 열어 원하는 값을 수정할 수 있습니다.

예시: "체력 30% 이하에서 3초마다 번개 3줄기를 떨어뜨려 피해 45를 준다. 그 후 방어막을 2초 유지한다."

브라우저가 한국어 입력을 지원하는 **LanguageModel Prompt API**를 제공하고 모델이 이미
사용 가능한 경우에는 기기 내 AI로 JSON 제작을 시도합니다.
그 외에는 한국어 문장 규칙으로 분석합니다. API 지원 여부 및
언어 지원은 기기마다 다릅니다. 지원되지 않는 기믹이나 자유로운 자연어를

## Ability Atlas — 210개 실제 공격 동작 조합

스킬 제작기에 **공격 동작 도감 210가지**가 추가되었습니다.

공격 5종(투사체·광선·낙뢰·충격파·장판) ×
공격 배치 7종(직선 집중·부채꼴·방사형·일렬·십자·나선·무작위 산개) ×
대상 선택 6종(근거리·원거리·저체력·고체력·무작위·밀집 대상)
= **210개 전투 판정 조합**입니다.

단순 이름 차이가 아니라 실제 목표 선택, 투사체 발사 방향,
낙뢰/장판 중심 좌표, 빔 방향, 충격파 중심점 등이 달라집니다.
상태이상, 지속 시간, 동작 순서, 피해량, 개수까지 조정 가능하므로
실제 조합 가능 수는 훨씬 더 많습니다.

**사용법:** 커스텀 캐릭터 → 문장 분석으로 자동 생성하거나,
접힌 **공격 동작 도감 · 210가지**에서 검색해 선택합니다.
세부 설정에서는 각 동작의 공격 배치/대상 우선순위를 수정할 수 있습니다.

자연어 예시:
- "3초마다 가장 멀리 있는 적에게 부채꼴 화염탄 5발을 발사한다."
- "체력 30% 이하일 때 뭉쳐 있는 적에게 십자 모양으로 낙뢰 4줄기를 떨어뜨린다."
- "2초마다 체력이 가장 낮은 적의 주변에 나선형 장판 6개를 만든다."

**계수 기준:** 도감에는 210개의 서로 다른 *조합 프리셋*이 있으며,
210개의 독립적으로 새로 작성한 물리 엔진이 있는 것은 아닙니다.
모든 공격 배치는 투사체/광선/낙뢰/충격파/장판의 공통
전투 엔진을 재사용합니다. 복잡한 분신 AI·전장 전체 시간 되감기 등은 아직
독립적인 전투 기능으로 지원하지 않습니다.


## 한국어 유의어 / 문맥 해석 개선

캐릭터 능력을 설명할 때 정확히 같은 스킬 단어를 입력할 필요는 없습니다.
한국어 유의어를 공통 의미로 변환한 다음, 발동 조건과 동작 순서를 분리하여 전투에 적용합니다.

- 이동 · 순간이동 · 텔레포트 · 텔포 · 점멸 · 워프 → 텔레포트
- 번개 · 벼락 · 낙뢰 · 천둥 · 전격 · 뇌격 → 낙뢰
- 독 · 독딜 · 도트데미지 · 도트딜 · DOT · 중독 · 지속 피해 → 독 지속 피해(DoT)
- "3초마다 이동 후 독딜" → 3초 주기의 텔레포트 후 독 장판
- "2초마다 낙뢰로 독딜 20" → 낙뢰에 독 상태이상 부여
- "이동 속도 3.2" → 이동 속도 설정. 스킬 텔레포트로 오인하지 않음
- "5초 동안 독딜" → 피해량 5가 아니라 지속 시간 5초로 해석

독 장판은 처음 생성될 때도 명중 판정을 수행하며, 독 피해의
지속시간/주기적 피해량은 전투 루프에 반영됩니다.

브라우저가 어디서든 쓸 수 있는 완전한 자연어 AI 서버를 기본 제공하는 것은 아닙니다.
기본 해석은 명시적인 유의어·문맥 규칙으로 작동합니다. 지원되는 기기에서는
브라우저 내장 언어 모델을 추가로 시도합니다. 전혀 새로운 동작이나

## Advanced Combat — 높이 기반 전투와 물리 오브젝트

공통 높이 모델은 캐릭터의 **바닥 위치 (x, y)**와 **높이 z**를 구분합니다.
공중에서는 캐릭터만 y-z로 그려지고 그림자는 바닥에 남습니다.
높이에 따라 몸이 커지고 지하에서는 작아지며 반투명해집니다.
기존 박성원 jumpHeight도 같은 높이 판정의 입력으로 사용합니다.

**추가된 20가지 동작**: 도약, 체공, 활공, 급강하, 어퍼컷, 베기,
회전베기, 찌르기, 공중 연속 공격, 곡사탄, 분열탄, 벽 설치,
쌍방향 포탈, 추적 소환수, 자동 포탑, 덫, 거대화, 소형화,
땅굴 돌진, 솟구치기.

- 판정은 높이 차이를 포함합니다. 지상 공격이 고공/지하 대상을 자동으로 맞히지 않습니다.
- 어퍼컷은 상대를 실제로 띄웁니다. 공중 공격은 위치와 판정이 연결됩니다.
- 베기는 부채꼴 예고 후 시전자 방향으로 타격합니다. 찌르기는 좁은 직선 공격입니다.
- 곡사탄은 포물선으로 상승·하강하며 지상 착탄 시 피해를 줍니다.
- 분열탄은 비행 중 여러 파편을 만들어 각자 이동·공격합니다.
- 벽은 실제 충돌/체력, 포탈은 쌍방향 이동과 재진입 대기시간을 갖습니다.
- 소환수는 추적하고 포탑은 고정 위치에서 공격합니다. 시간/체력을 표시합니다.
- 거대화와 소형화는 시각 크기뿐 아니라 충돌 반경도 변경하며 종료 시 복원됩니다.
- 기존 ForgeExpansion의 공중 강하와 지하 습격도 공통 높이 시스템을 공유합니다.
- 구조물/탄환 개수는 제한하고 재매칭 시 정리합니다.

자연어 예문: "어퍼컷으로 띄우고 공중 연속 공격한다",
"분열탄 3개를 발사한다", "벽을 설치하고 포탈을 연다",
"추적 소환수와 포탑을 설치한다".

**제약**: 2D 탑뷰 화면에 높이 좌표를 적용한 2.5D 전투입니다.
실제 브라우저에서 모든 조합의 시각적 확인은 별도 QA가 필요합니다.


## 점프·공격 연출 품질 개선

- 공통 점프를 도약 준비(몸 압축) → 상승(세로 늘어남) → 체공(부드러운 흔들림) → 하강 → 착지 반동으로 연결
- 박성원의 기존 점프는 고유 타이밍을 유지하되 같은 공통 몸 동작 및 바닥 그림자 체계를 사용
- 공중에서 높이 z를 따라 캐릭터와 그림자가 분리되며, 착지 시 바닥 압력 고리와 흙먼지가 퍼짐
- 물리 업데이트는 60Hz 고정 스텝, 화면 그리기는 requestAnimationFrame 기반. 두 스텝 사이 위치 보간으로 60Hz 이상 화면에서도 뚝뚝 끊기는 이동을 완화함. 단 실제 60fps 보장은 기기 성능과 브라우저에 따라 달라짐
- 베기·찌르기·회전베기는 점선 예고와 진한 검격 진행선을 분리해 표현
- 곡사탄·분열탄은 실시간 탄환 잔상과 위치 보간을 적용
- 벽에는 생성 애니메이션·실물 형태의 경계선, 포탈에는 맥동·회전 링, 소환수에는 작은 부유 움직임을 적용
- 파티클·효과음은 절제된 강도로 넣고 기존 화면 효과 줄이기 옵션에 따라 잔상/먼지의 양을 축소함
- 전투 판정은 기존 높이 기반 충돌 모델을 그대로 공유하며 이펙트 연출만을 위한 가짜 피격은 만들지 않음

자동 테스트는 애니메이션 단계, 착지, 이동 보간과 읽기 전용 렌더링까지 검증합니다. 시각적 디테일과 체감 FPS는 별도 실기 확인이 필요합니다.


## 제작기 UI 통합 및 스킬별 독립 재사용 대기시간

- 기본 화면은 캐릭터 이름 → 자연어 설명 → 문장 분석 → 캐릭터 저장·출전으로 단순화합니다.
- 기존 중복 미리보기 버튼을 기본 화면에서 제거하고, 스킬 구성 확인은 고급 설정에 배치합니다.
- 랜덤 초안, 스킬 수치 직접 수정, 동작 도감, 외형·기본 수치, 내 캐릭터·공유·JSON은 각각 접어서 관리합니다.
- 기존 저장 캐릭터와 공개 GitHub Issues 공유 방식은 유지합니다.
- 4개까지의 각 스킬은 서로 다른 cooldownFrames, forgeTicks[i]를 사용해 독립적으로 충전하고 발동합니다.
- 스킬 A의 연속 동작과 스킬 B의 발동은 서로 기다리지 않습니다. 한 스킬의 연결 동작은 스킬 순서를 유지하고, 매 동작의 명시적 발동 지연도 보존합니다.
- 기절·침묵 중에도 타이머는 충전됩니다. 실행 대기 중인 스킬 동작은 삭제하지 않고 상태 해제 후 실행됩니다.
- 경기 화면의 캐릭터 체력 UI 아래에 각 스킬의 개별 충전 게이지와 남은 시간이 표시됩니다.
- 능력 오버클럭 아이템은 제작 캐릭터의 스킬별 쿨타임에도 적용됩니다.
- 큰 피해가 발생할 때 물리 업데이트를 멈추던 히트스톱을 제거해 연출 때문에 의도적으로 생기는 끊김을 줄였습니다.
- 상승 중인 도약 다음의 급강하·공중 콤보는 정점까지 기다려 연결하며, 어퍼컷 → 공중 콤보 시에는 시전자도 따라 도약합니다.

물리 업데이트는 60Hz 고정 스텝이며, 브라우저 프레임률은 성능·화면 주사율에 따라 달라집니다. 끊김 없는 60fps를 모든 기기에서 보장한다는 의미는 아닙니다.


## 전투 판정 ↔ 동작 ↔ 이펙트 일치 개선

- 제작 캐릭터에서 20개 고급 동작을 실제 전투 모듈로 호출하도록 연결합니다. 이전처럼 메뉴에만 노출되고 시전이 누락되는 경우를 방지합니다.
- 베기: 시전자를 기준으로 실제 부채꼴 사거리까지 칼날이 휘둘러지며, 명중 후에만 대상 위치에 칼집 흔적을 남깁니다.
- 찌르기: 실제 직선 궤도와 동일한 길이의 창끝이 뻗고, 직선과 닿은 적에게만 피해를 줍니다. 맞은 곳에는 찌른 자국이 생깁니다.
- 회전베기: 전방 부채꼴이 아닌 완전한 원형 공격 범위를 표현하며, 맞은 곳에 교차 절단 자국이 남습니다.
- 공중 연속 공격: 이제 세 번의 독립된 타격 타이밍을 사용하고, 첫 타격 성공 시 서로 공중으로 뜹니다.
- 곡사탄: 무거운 원형 포탄과 그림자·포물선 이동으로 표시하고, 지면 착탄 시에만 폭발/피해가 발생합니다.
- 분열탄: 금이 간 결정 형태, 파편: 방향성이 보이는 화살촉 형태로 구별합니다. 파편은 이전 프레임에서 현재 프레임까지 통과한 실제 경로로 충돌을 계산합니다.
- 일반 제작 탄환도 화염·빙결·독·무속성 투사체의 실루엣을 구분하며 위치 보간을 사용합니다.
- 포탑·소환수의 공격선은 피해자가 아닌 실제 공격 출발점에서 목표까지 연결됩니다.
- 설치 벽은 원형 충돌 반경의 윤곽을 화면에 표시합니다.
- 생성기 세부 설정과 동작 안내에 20개 고급 동작의 실제 효과와 명중 조건을 설명합니다.
- 이펙트만 보였는데 실제로는 맞지 않는 경우를 줄이기 위해 명중 흔적은 피해 처리 성공 후 생성됩니다.

이 변경은 전투의 공격/투사체 물리와 표현 일치를 개선하는 1차 정리입니다. 전체 스킬 시스템에 대한 모든 장치·상태이상·혼합 연계의 수동 시각 검증까지 완료했다는 의미는 아닙니다.


## 전투 동작 · 추적 소환수 · 별비 · 전체 능력 · 완전 랜덤

- 추적 소환수는 개별적인 펫 모양과 방향 전환을 갖고 적을 따라갑니다. 원격 타격이 아니라 실제 접촉 거리에서 공격합니다. 포탑은 원격 공격입니다.
- 우주 별비는 오각별 여러 개가 꼬리와 그림자를 갖고 시간차로 떨어지며, 지면에 충돌하는 순간만 폭발·피해 판정을 발생시킵니다.
- 유도탄·관통탄·부메랑, 블랙홀·생명의 꽃·지뢰를 실제 동작에 맞는 실루엣으로 구별합니다.
- ‘모든 능력을 가진다’ 등의 문구는 전체 능력 모드로 저장합니다. 실제 경기 인스턴스는 로드된 모든 동작 타입에 대해 독립된 스킬과 타이머를 갖습니다. 과부하를 방지하기 위해 자동 발동은 6 시뮬레이션 틱마다 최대 한 개씩 공정하게 순환합니다.
- ‘전체 랜덤’은 이름·색상·체력(140~500)·속도(0.6~5.0)·스킬 수(1~4)·연계 동작 수(1~3), 모든 동작 타입·발동 조건·대상·패턴·피해량·범위·개수·상태이상·속도·지속시간·넉백·지연·쿨타임을 무작위로 결정합니다. 지정 테마는 첫 동작에만 가중치를 부여합니다.
- 전체 능력 모드는 실제 모든 스킬 쿨타임을 유지하면서 HUD에는 다음 순서의 네 스킬만 표시합니다.


## P0: 전투 규칙·표시 범위 일치 (2026-10-28)

- **공격 결과 일원화:** 고급 스킬의 지연 타격(베기·공중공격·소환수 등)은 같은 `SkillForge.hit` 처리기를 경유하도록 연결합니다. 피해 증감(공격 약화·취약·피해 감소), 넉백, 빙결/기절/독 등 상태이상을 동일하게 계산합니다.
- **행동과 이미 생성된 효과의 분리:** 기절·빙결·침묵은 새로운 시전을 막지만, 이전에 생성된 일반 투사체·장판·회전 구체·확장 필드의 물리 시계는 계속 흐릅니다. 개별 재사용 대기시간도 독립 충전됩니다.
- **회전 소환체:** 시전자 중심의 보이지 않는 전체 원형 공격을 없애고, 화면에 실제 표시되는 작은 소환 구체 위치와 적이 접촉할 때만 주기적으로 타격합니다.
- **지속 장판:** Ability Atlas가 만든 셀의 실제 반경을 저장하고 첫 타격·이후 주기적 타격·지면 시각화에 동일하게 사용합니다.
- **지뢰·운석·블랙홀·생명의 꽃:** 실제 범위 반경을 시각적으로 표시합니다. 기존 지뢰/운석의 발동 조건이나 전체 데미지를 임의로 약화시키지 않습니다.
- 회귀 테스트: 지연 피해의 방어·상태·넉백, 상태이상 도중 비행체/장판, 회전 구체 실제 접촉, 지면 표시 범위와 타격 거리 일치.



## P1: 물리 동작 완성 1차 (2026-10-28)

- 어퍼컷은 즉시 적을 띄우지 않고 준비 동작을 표시한 뒤 **8번째 물리 틱의 실제 접촉 위치**에서 타격합니다. 범위 밖으로 피한 적은 맞지 않습니다.
- **어퍼컷→공중 콤보**는 어퍼컷이 실제 명중할 때만 시전자가 함께 점프합니다. 후속 칼날은 시전 당시 높이가 아닌 **각 타격 순간 현재 높이**에서 판정합니다.
- **운석**은 바닥에 예고된 피해 반경과 그림자를 보여주는 동안, 큰 암석과 불꽃 꼬리가 45틱 동안 하강합니다. 착지했을 때만 기존 피해 판정이 발생합니다.
- **자동 포탑**은 매 발사 시각 적을 조준하고 실제 이동하는 탄환을 생성합니다. 피해는 조준 즉시가 아니라 탄환이 대상에게 닿은 시점에 발생합니다. 전용 탄환 모양과 포신 방향을 사용합니다.
- **장벽**은 원형 물리 충돌 경계로 일반 제작 탄환, 확장 탄환, 고급 탄환 및 자동 포탑탄을 가로막습니다. 막힌 발사체는 소멸하고 벽 내구도가 실제로 감소하며, 벽이 파괴되면 파손 흔적이 남습니다. 지면 장벽보다 높이 날아가는 곡사탄은 통과할 수 있습니다.
- 자동 회귀 테스트는 준비 중 공격 회피, 공중 높이 판정, 포탑의 실제 비행·명중, 벽의 탄환 차단과 파괴, 운석의 실제 하강 시점까지 검사합니다.



## P2: 55종 행동별 고유 발동·명중 시그니처 + 랜덤 생성 버튼

- `js/features/skill-visuals.js`에 **등록된 55종 동작 각각**을 서로 다른 작은 기하 도형·선·궤적으로 표시하는 독립적인 시각 모듈을 추가했습니다. 화염/운석/별비/소환수처럼 물리 애니메이션이 따로 있는 스킬은 그 움직임을 교체하지 않고 보조 신호만 얹습니다.
- 신호는 **실제로 동작이 실행된 시점**(단순 예약·쿨다운 시작이 아님)에만 나타나고, 명중 표시는 **실제 피해/상태이상 적용 성공 시** 상대의 해당 위치에 생성됩니다. 적이 피해를 피하거나 무적이라면 가짜 명중 이펙트가 생기지 않습니다.
- 게임 화면의 fixed-step 60Hz 업데이트와 함께 시계를 진행하고, 최대 68개까지만 유지합니다. 재매칭 시 모두 지우고 이펙트 줄이기 설정에 따라 가는 선으로 렌더링합니다.
- 캐릭터 생성기의 1차 버튼 줄에 **‘🎲 완전 랜덤 생성’**을 추가했습니다. 전체 동작 풀에서 랜덤 초안을 만든 뒤 기존의 안전한 저장·P1 출전 경로를 즉시 사용합니다. 기존 랜덤 테마 초안 메뉴는 선택적으로 유지됩니다. 진행 중 경기에서는 생성되지 않으며 6명 제한을 안내합니다.
- 이번 P2의 범위는 스킬을 구분하기 위한 독립적인 발동·명중 시각 언어이며, 모든 55종의 장시간 상태 모션·입력 설정값 일치(P3)까지 완료했다는 의미는 아닙니다.


## P3: 55종 설정값 감사·한국어 의미 기반 스킬 구분·랜덤 버튼 노출

- **55종의 동작별 유효 입력 목록**(`SkillForge.ACTION_PARAMETERS`)을 정의했습니다. 스킬 세부 편집에서는 실제 실행 로직이 읽는 항목만 보여주며, 모든 동작이 공유하는 발동 지연은 유지합니다. 기존 저장 JSON의 모든 속성은 보존하므로 이전 캐릭터는 계속 불러올 수 있습니다.
- **대상 우선순위**는 Atlas 5종뿐 아니라 실제 고급 전투/확장 동작에도 동일한 대상 선택기를 사용합니다.
- **곡사탄/분열탄**은 속도 설정에 따라 실제 비행 시간이 변하고, 분열탄의 '개수'는 파편 수를 의미합니다(원탄 수 × 파편 수가 아닙니다). **운석/별비** 역시 설정 속도를 낙하 시간에 반영하며 낙하 그림과 착탄 판정은 한 시계를 사용합니다.
- 랜덤 생성 버튼은 접혀 있는 랜덤 테마 메뉴나 문장 분석창 아래가 아니라, **캐릭터 스튜디오 제목 바로 아래 독립 안내 영역**에 배치했습니다. 누르면 전체 55종 풀에서 캐릭터를 생성해 기존 저장·P1 출전 흐름으로 연결합니다.
- 한국어의 **'-고', '그리고'**는 단순 구분자가 아닙니다. 의미가 이어진 공격(베고 찌른다)은 한 스킬의 연계 동작, 기절/중독처럼 같은 공격의 후속 상태 설명은 한 동작의 부가 효과, 독립 방어 능력이나 별도 발동 조건은 다른 스킬로 해석합니다. '그리고'처럼 두 해석이 가능한 경우에는 **별개 스킬 / 연계 동작** 중 선택하도록 질문합니다.
- 기본 오프라인 분석은 규칙·키워드·문맥 단서를 이용한 의미 분류이며, AI 서버의 일반적인 자연어 이해와 동일하지 않습니다. 모호한 표현은 사용자가 선택해 오류를 줄입니다.
- 모든 캐릭터나 특수 기술의 실제 그래픽 완성도를 브라우저에서 시연했다는 뜻은 아닙니다. 이번 단계의 자동 테스트는 입력 유효성, 물리 속도 및 의미 분석 경계에 초점을 맞춥니다.


## UI 카테고리 정리 (2026-10-28)

- **상단 카테고리 내비게이션**: 경기 / 대진 설정 / 캐릭터 제작 / 사진·꾸미기 / 베팅·상점 / 파이터 가이드로 구분합니다. 모바일에서는 한 줄 가로 스크롤로 겹침을 방지하고, 현재 위치를 명확하게 강조합니다.
- **대진·제작·사진**은 한 도구 패널의 세 탭으로 전환합니다. 기존 대진 선택/사진 업로드/캐릭터 저장·수정 DOM과 이벤트는 제거하지 않고 이동시켜 기능을 보존하며, 탭은 화살표·Home·End 키보드 이동을 지원합니다. 경기장은 언제나 독립적으로 보입니다.
- **캐릭터 제작**: 가장 중요한 랜덤 즉시 생성, 이름, 자연어 분석, 저장 버튼 순으로 배치하고, 외형·기본 능력 / 고급 스킬 편집 / 스킬 도감 / 테마 랜덤 초안 / 내 캐릭터·공유·JSON을 각각 접을 수 있는 영역으로 정리합니다.
- **베팅·상점**: 예측과 베팅을 먼저 보여주고, 아이템 구매·예약은 별도의 상점 영역에서 펼칠 수 있도록 합니다.
- **오류 수정**: 기존 자연어 생성기의 설치 단계에서 `randomNow` 버튼을 선언하기 전에 사용하여 발생하던 초기화 오류를 해결했습니다. 따라서 버튼이 보이지 않거나 생성기가 작동하지 않을 수 있었던 원인을 없앴습니다.
- 스타일은 중성 회색 계열로 차분하게 유지하고 PC/모바일 반응형 너비, 줄바꿈, 포커스 가시성, 감소된 모션 설정을 적용합니다. 게임 기능과 데이터 형식은 그대로 유지합니다.
- 자동 DOM 동작 테스트는 카테고리 전환, 기존 요소 보존, 상점 분리, 스크롤, 소스 로딩 순서 및 랜덤 생성 버튼 선언 순서를 확인합니다. 실제 브라우저에서 전체 기능과 픽셀 겹침에 대한 별도 시각 테스트도 권장합니다.
